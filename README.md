## 📋 Descripción de los Ejercicios

Este proyecto abarca la resolución de dos problemas fundamentales basados en el texto guía del curso (autor: *Leonardo Bermón Angarita*):

### 📌 Ejercicio 1: Cálculo Estadístico de Notas
Programa en consola diseñado para gestionar un arreglo de 5 notas académicas mediante programación orientada a objetos. Realiza las siguientes operaciones:
* Ingreso y validación robusta de datos numéricos.
* Cálculo del **promedio aritmético**.
* Cálculo de la **desviación estándar**.
* Identificación de la **nota mayor** y la **nota menor**.

### 📌 Ejercicio 2: Figuras Geométricas con Herencia y GUI (Swing)
Implementación orientada a objetos que aplica los principios de **herencia** y **polimorfismo** con una interfaz gráfica de usuario (GUI):
* **Superclase:** `FiguraGeometrica` (gestiona atributos comunes de volumen y superficie).
* **Subclases:** `Cilindro`, `Esfera` y `Pirámide` (con sus respectivas fórmulas matemáticas de cálculo).
* **Interfaz Gráfica (Swing):** Ventana principal interactiva que despliega formularios dinámicos para capturar los parámetros de cada figura e imprimir los resultados en tiempo real.
